TalentHunt — AI-Assisted Recruitment & Resume Matching Platform

A recruitment application exploring how semantic retrieval, lexical matching, and LLM-assisted evaluation can support recruiter workflows — from job posting through resume review.

Recruiters often spend significant time manually comparing resumes against job descriptions and reviewing first-pass candidate suitability. Simple keyword matching misses relevant candidates whose resumes are phrased differently from the job description.

A recruitment application with recruiter/candidate role-based workflows, resume processing, Resume–JD matching, and AI-assisted candidate evaluation. It combines semantic similarity with lexical/fuzzy matching to improve Resume–JD comparison beyond exact keyword matching, then uses an LLM to produce a contextual evaluation for recruiter review.

  • Frontend: React
  • Backend: Python + FastAPI, modular API routes
  • Database: MySQL
  • Authentication: JWT with role-based recruiter/candidate access
  • Resume extraction: PyMuPDF
  • Semantic representation: Sentence Transformers
  • Vector retrieval: ChromaDB
  • Lexical/fuzzy comparison: RapidFuzz
  • LLM integration: Groq-hosted LLM API
  • Deployment setup: Docker Compose + Nginx
